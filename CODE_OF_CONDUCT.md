# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work. Harassment of any kind isn't tolerated.

To report a problem privately, use **Report a vulnerability** on this repository's Security tab and mark it as a conduct report, or email the maintainers at contact@dynamiclly.com.
